01 — Master identity · typography

Type is the loudest part of the brand.

Thmanyah is used ONLY as the Arabic display face, in its Sans cut, heavy weights, for Level 01 headlines. It never carries body text, labels or English. Everything around it — Plex Arabic text, Archivo numerals, Plex Mono index labels, the Square Stop, the Strike, blue/black Fields — is what makes the result read as Gouraan and not as the foundry's own media brand. Every Arabic headline on these boards is set in the real Thmanyah Sans files; everything smaller than a headline is IBM Plex Sans Arabic.

AR 01 · Display
Thmanyah Sans — Bold 700 / Black 900
حسام جعران
Contemporary, confident Arabic with calligraphic memory. Heavy weights hold at thumbnail size. Sans only — the Serif Display cut is the one most associated with Thmanyah's own brand, so it is excluded.
AR 02/03 · Secondary + Body + UI
IBM Plex Sans Arabic — 400–700
أبني وأجرّب وأسأل
Rational, engineered, very readable at 14–22 px. Its Latin sibling (Plex Sans / Plex Mono) gives mixed-language lines a single rhythm — the "systems thinker" voice.
EN 01 · Display + Numerals
Archivo — 800, width 87.5
Build. Question.
A grotesque with real editorial bite and a width axis: semi-condensed headlines and giant episode numerals (01–100) that sit well next to heavy Arabic without shouting "tech".
EN 02/03 · Text
IBM Plex Sans — 400–600
Strategy is a choice.
The Latin partner of the Arabic body face. Used for LinkedIn copy, website EN and subtitles in English.
META · Index / numbers

The builder's notebook voice. Every episode marker, source line, timestamp and the Index Tab. Uppercase, +8 % tracking, Western digits.
Not used

Thmanyah Sans — the real family, five weights
Hierarchy on a 1920 × 1080 specimen
Mixed Arabic + English
  • Scale ratio ≈ 1.7 between levels: 160 → 96 → 56 → 32 → 22 → 18 → 14 (Arabic, px at 1920/1280).
  • Line height Arabic display 1.08–1.15; Arabic text 1.6–1.85 (dots and marks need room); English display 0.92–0.96; English text 1.5–1.6.
  • Tracking Arabic always 0 — never letter-space Arabic. English display −2 %; mono +8 %.
  • Arabic alignment right, ragged left. Never centred except the one-line end card. Never justified (kashida stretching is banned).
  • English alignment left, ragged right, in its own LTR block.
  • Line breaks are written by hand on display lines: 1–3 words per line, never break a phrase that belongs together.
  • Mixed lines an English word inside an Arabic headline (AI, CEO, MVP) is set in the SAME display face at the same size — no switch to Archivo mid-line.
  • Numbers Western digits everywhere (01, 90, 2026) for one visual system across languages; always two digits for episodes.
  • Diacritics only where a word would be misread (المسلَّمات).
